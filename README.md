# Jivika Rahane — Portfolio

Static site for GitHub Pages. Pages: index, about, projects, contact, resume.

## Deploy
1. Upload everything in this folder to the root of your `portfolio` repo (replace the old HTML/CSS/JS).
2. **Keep your existing `assets/` folder** (project images, resume.webp, og-image.png) — it is not included here.
3. Commit; GitHub Pages updates in 1–2 minutes.

## Task 2 features
- CSS Grid: page layout, skills, cards, projects
- Flexbox: header, nav, buttons, footer
- Mobile-first media queries (600px / 900px / 1200px)
- CSS variables with light/dark theme toggle
