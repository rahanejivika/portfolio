Concept / academic project

MSRTC Live Bus Tracking & Management System

Problem

Public bus commuters and transport staff often lack real-time visibility into where buses are on their route, making it hard to plan journeys or monitor fleet movement and schedules.

Solution

A concept for a live bus tracking and management dashboard that plots buses on a route map and gives staff a management screen for routes, schedules and bus status — improving visibility for both commuters and operators.

Technologies

HTML, CSS, JavaScript, UI/UX design, system design & flow diagrams

  • Web App Concept
  • UI/UX
  • System Design

Presented as a design/coursework concept, not a deployed system.

Concept / academic project

AgriMind AI

Problem

Many farmers need quick, accessible agricultural guidance — such as crop and plant identification or general farming advice — but may not have easy access to experts or find existing tools hard to use in their own language.

Solution

A concept for an AI-based agricultural assistant that accepts voice and image input, offers crop-related guidance, and supports multilingual interaction so farmers can get help in a way that's natural for them.

Technologies

JavaScript, AI/LLM concepts, API integration, multilingual interfaces

  • AI Concept
  • JavaScript
  • Multilingual UX

Presented as a design/coursework concept, not a deployed system.

Concept / academic project

TreePlantAI

Problem

Choosing which tree species to plant, and how to lay out a plantation, can be difficult without guidance on local conditions, spacing, and suitability of different species.

Solution

A concept for a rule-based recommendation and planning tool that helps a user pick suitable tree species (such as Neem, Mango, Teak or Banyan) and visualise a simple plantation layout on a grid before planting.

Technologies

JavaScript, rule-based recommendation logic, interactive grid UI

  • Planning Tool
  • JavaScript
  • Rule-based Logic

Presented as a design/coursework concept, not a deployed system.

Concept / academic project

HostelHub

Problem

Managing hostel rooms, student records, and bed allocations by hand is time-consuming and error-prone, making it hard to keep track of who's assigned where and how much capacity remains.

Solution

A concept for a digital hostel management system with a visual room floor plan, resident detail records, and allocation tools, plus summary stats like occupancy rate to simplify day-to-day management.

Technologies

PHP, SQL/database design, HTML, CSS

  • Management System
  • PHP
  • Database Design

Presented as a design/coursework concept, not a deployed system.

Coursework / educational material

Robotics Component Presentations

Problem

Understanding how a robotic arm's joints, links, and end effector work together can be difficult from text alone — it helps to see each component labelled and explained visually.

Solution

A set of structured coursework presentations that break down robotic arm anatomy — joints, links, and the end-effector gripper — using clear, labelled diagrams to support classroom learning.

Technologies

Presentation design, robotics fundamentals, embedded concepts

  • Coursework
  • Robotics
  • Presentation Design

Educational/coursework material, not a deployed robotic system.
