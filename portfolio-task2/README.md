# Task 2 — Advanced CSS3 & Responsive Architecture

Upload the `css/` and `js/` folders to the root of your `portfolio` repo (merge with existing folders).

Add to the `<head>` of index.html, about.html, projects.html, contact.html, resume.html (after your existing stylesheet):

    <link rel="stylesheet" href="css/advanced.css">

Add just before `</body>` on each page:

    <script src="js/theme.js"></script>

Features: CSS Grid layouts, Flexbox components, mobile-first media queries, CSS variables with light/dark theme toggle.
